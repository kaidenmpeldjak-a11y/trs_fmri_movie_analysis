# trs_fmri_movie_analysis
Pipeline used to analyze social cognition features within short films on a per-frame basis. Frame data were then reduced into correlated regressors with fMRI data.  

Methodologies used for rating emotional tone present in the short film clips were adapted from the Python code developed by Severi Santavirta et al., in their published work “GPT-4V shows human-like social perceptual capabilities at phenomenological and neural levels” (2025)
